# Mood Based Music Recommendation System

A Flask-based machine learning web application that detects user emotions from text input and recommends songs based on the detected mood.

## Features

- Emotion Detection using NLP
- TF-IDF Vectorization
- Logistic Regression Model
- Song Recommendation System
- Flask Web Interface

## Technologies Used

- Machine Learning
- Python
- Flask
- Scikit-learn
- Pandas
- HTML

## How To Run

1. Activate virtual environment

2. Install dependencies

pip install -r requirements.txt

3. Run Flask app

python app.py

4. Open browser

http://127.0.0.1:5000
